# Villa Kaia — Vercel

Standalone migration with the same seven scroll-controlled film segments, HR/EN/DE copy, real photos, indicative seasonal pricing and email enquiries.

Run `npm ci`, `npm run typecheck`, `npm run build` with Node 24. Deploy this folder to Vercel. Nitro produces `.vercel/output`. No Higgsfield account or secrets are required by the application. The `app/` directory is an untouched backup of the original export and is excluded from deployment.

Production access must be checked without any login after deployment. Prices are indicative; the calendar selects requested dates, not synchronized availability. Enquiries open the visitor’s mail application to mpercec.private@gmail.com.
